# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. The full text is at that link; the sections below are the parts a reporter needs
without following it — in particular **how to report**, which the previous version of this file
left to inference.

## Our pledge

We as members, contributors, and leaders pledge to make participation in our community a
harassment-free experience for everyone, regardless of age, body size, visible or invisible
disability, ethnicity, sex characteristics, gender identity and expression, level of experience,
education, socio-economic status, nationality, personal appearance, race, religion, or sexual
identity and orientation.

## Scope

This Code applies in all project spaces — issues, pull requests, discussions, commit messages
and code review — and when an individual is officially representing the project in public.

## Reporting

**Report through GitHub:**
[open a private security advisory](https://github.com/anonceleb/Kestrel/security/advisories/new),
which is a private channel between you and the maintainers, and write `CONDUCT` in the title.
The maintainers are named in [NOTICE](./NOTICE).

We use that channel rather than an email address so that reports are private, delivered to
both maintainers, and do not depend on a personal inbox that will change when the LLP is
incorporated. If your report concerns a maintainer, say so — see *Conflicts of interest*.

Reports are acknowledged within **7 days**. All complaints will be reviewed and investigated
promptly and fairly. The reporter's identity and the details of any incident will not be
shared beyond the people handling it.

## Conflicts of interest

This is a two-person project, so a report may concern one of the two people who would
otherwise handle it. If it does:

- the maintainer named in the report takes no part in reviewing it;
- if the report concerns both maintainers, or you would rather not route it through either,
  escalate to the neutral steward once one exists (`spec/CFP-v0.x.md` §8 commits to naming
  one). Until then, we would rather you raise it publicly than not at all, and we will not
  treat doing so as a violation.

Stating this plainly is better than implying an impartiality a project this size cannot claim.

## Enforcement guidelines

Following the Contributor Covenant's four-step ladder — **Correction**, **Warning**,
**Temporary ban**, **Permanent ban** — applied proportionately, with the reason given in
writing to the person concerned.
