The industry already solved this for payments. This applies the same answer to fulfilment.

Agentic checkout protocols (ACP — the OpenAI/Stripe-developed Agentic Commerce Protocol) already draw a line: payment data travels as a scoped, single-merchant, single-amount token. Fulfilment data does not — it still travels as a plaintext address object in the same request.

"The industry already agreed agents hold scoped tokens, not card numbers. This applies the same conclusion to the address."

ACP checkout today

fulfillment_address: plaintext

// checkout_session.create — request body
{
  "line_items": [{ "item": { "id": "sku_412" }, "quantity": 1 }],
  "fulfillment_address": {
    "name": "Priya N.",
    "line_one": "14 Harbour Lane",
    "line_two": null,
    "city": "Calder",
    "state": "KA",
    "country": "IN",
    "postal_code": "4820"
  },
  "payment_data": { "token": "spt_9f2c...", "provider": "stripe" }
}

Payment carries a token — scoped to one seller profile, one currency, one amount, one expiry (Stripe Shared Payment Tokens). Fulfilment carries the address in the clear, in the same request, to every party in the checkout path: the agent runtime, the merchant, any logging middleware in between.

Same checkout, capability instead

fulfilment_grant: a scoped token

// checkout_session.create — request body
{
  "line_items": [{ "item": { "id": "sku_412" }, "quantity": 1 }],
  "fulfilment_grant": {
    "id": …,
    "pairwiseId": …,
    "maxUnits": 1,
    "channelKind": "locker",
    "expiresAt": …,
    "singleUse": true,
    "mac": …
  },
  "payment_data": { "token": "spt_9f2c...", "provider": "stripe" }
}

Live in this page: the token above is minted client-side against the same HMAC shape packages/capability uses server-side. The agent, the merchant, and anything logging this request see a grant that resolves to nothing without the vault.

Verified facts cited on this page

  • ACP checkout schema — fulfillment_address as a plaintext Address object, payment_data as a token — schema version 2025-09-29, main branch of the Agentic Commerce Protocol repository.
  • ACP was co-developed by OpenAI and Stripe, released 29 September 2025 (Stripe newsroom). This page does not claim Meta co-authorship or any 2026-04-17 date — both were checked against primary sources and did not verify; neither appears here.
  • Stripe Shared Payment Tokens are scoped to one seller profile, one currency, one maximum amount, and one expiry — the asymmetry this page names (payment tokenized, fulfilment not) is structural, not a reading of intent.
