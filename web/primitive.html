Notes

The MAC covers {id, caveats, chain} — id is signed material because single-use enforcement (NonceLedger.burn) is keyed on it alone; a MAC that didn't cover it would let a holder mint unlimited "single-use" tokens by swapping ids. attenuate() may only tighten: assertNotWidened rejects any increase in maxUnits/expiresAt, any pairwiseId change, any singleUse relaxation, and any purpose change — the one sanctioned transition (delivery → return) lives in attenuateToReturn(), reachable only through Platform.createReturn. A replayed grant and a revoked one throw the same CapabilityBurned — the holder cannot tell "already used" from "the subject pulled it". Pinned in Node by tests/grant-core/ (INV-3, INV-11).
