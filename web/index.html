CFP — Confidential Fulfilment Profile
primitive agentic-flow address contact break-it candid-books

A capability to act on a sensitive attribute — never the attribute itself.

A FulfilmentGrant is a scoped, expiring, single-use, revocable, narrowing-only token that lets a counterparty cause an action (route a parcel, connect a call) against an attribute it never holds. The grant core carries no address vocabulary — address is its first attribute profile, contact/phone the second. Scope note: CFP begins after discovery; there is no search, catalog, or select-shaped code in this repo, by design.

Audience: protocol stewards evaluating whether an open network's grammar should carry this primitive. This is a proof of mechanism, not a product. Open problems are listed with the same prominence as closed ones — see candid-books.

2. Pages

candid-books Five threat-model gaps closed (with the tests that prove it), three still open, and the twelve-month stewardship hand-over clause, verbatim.

Every interactive element on these pages imports the repo's own modules from ./assets/js/ — per-file source SHA-256 in the manifest, transform is type-strip + import rewrite only (tools/web-build/build.ts). The one substitution is node:crypto → a pure-JS shim; the build runs 63 equivalence checks against node:crypto (digests, AEAD both directions, Ed25519 cross-verification) and aborts on any mismatch. Runs fully offline behind any static file server (python3 -m http.server from web/) — browsers require an HTTP origin for ES modules, but no network request ever leaves the page.
