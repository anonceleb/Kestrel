Eight attacks against the live objects on this page

On load, this page builds a real deployment in memory from the transformed repo modules: a registry seeded with a genesis facilitator, a vault holding an encrypted record, a minted grant. Each button attacks those objects. The error you see is thrown by the module, not printed by the page — the page's own handlers only catch and display. Each attack cites the Node test that pins the same invariant; run npm run verify to see all 52.

1. Replay a spent grant

Resolve the grant once, then present the identical token again. — tests/grant-core (INV-3)






  
2. Widen an attenuated grant

  
Take the narrowed grant and attenuate it back up to a higher maxUnits. — tests/grant-core (INV-11)

  





  
3. Forge the MAC

  
Flip one caveat (maxUnits 1 → 100) and present the grant with its original mac. — tests/grant-core (INV-2)

  





  
4. Correlate a subject across two counterparties

  
Derive the same subject's pairwise id at two counterparties; score shared structure with the
  repo's own linkability oracle. — tests/grant-core (INV-5)

  





  
5. Decrypt without an audit record

  
Call the vault's unaudited path directly. It exists only so the suite can prove it is a dead end. — tests/grant-core (INV-4)

  





  
6. Tamper with the stored ciphertext

  
Swap one record's ciphertext into another record's slot (or flip a byte) and resolve. AAD binds
  ciphertext to tenant|record — a moved row fails closed instead of returning the wrong person's address.

  





  
7. Sign a registry write with a non-facilitator key

  
A registered operator (not facilitator) signs a WriteAuth admitting a new participant. — tests/grant-core (INV-29)

  





  
8. Present a doctored Beckn envelope

  
Take a validly signed envelope, alter the body one byte, present both. BLAKE2b-512 body digest
  is part of the signed string. — tests/grant-core (INV-34)

  





  
+ Request a narrow cohort

  
Ask for a brand-facing cohort of 8, below the k=25 floor. — tests/profiles/address (INV-7)
