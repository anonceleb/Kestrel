For the skeptical reader

Five attacks. Each wired to the real primitive, not a scripted denial.

Every button below re-derives the same check the actual code runs in packages/capability, packages/identity, packages/core, and services/vault — client-side, because this is a static demo with no server. The failure mode named is the real one; it isn't a canned string.

1. Replay a spent grant

Redeem a grant once, then try again with the identical token.

2. Widen an attenuated grant

Take a narrowed grant and try to attenuate it back up to a higher maxUnits.

3. Correlate a subject across two counterparties

Derive the same subject's pairwise identifier at two different counterparties and check for shared structure.

4. Request a narrow cohort

Ask for a brand-facing cohort size below the k=25 anonymity floor.

5. Decrypt without an audit record

Call the vault's unaudited resolution path directly.
